# ============================================================
# GEO robots.txt 模板 — 主流 AI 爬虫显式放行清单
# 用法：把 di3zongdui.github.io 替换为你的域名后部署到站点根目录
# 维护：geo-infrastructure Skill
# 最后更新：2026-09-28
#
# 重要说明（免得后人误读本文件的作用）：
#   本文件底部有 "User-agent: * / Allow: /"，即全站对所有爬虫默认放行。
#   因此上方逐条声明的实际效果不是"开权限"（权限本来就有），而是
#   向爬虫运营方显式表达许可意图 —— 部分厂商按 UA 统计站点采纳率。
#   所以：删掉无效 token、补齐真实 token 属于准确性维护，不是增长杠杆。
#   真正的杠杆在索引收录与第三方实体提及，不在这里。
#
# 规则依据：RFC 9309（Robots Exclusion Protocol）。
#   规范允许行内注释（EOL = *WS [comment] NL），但本模板用独立行注释，
#   对自研解析器 100% 安全。
#
# 来源等级标注（2026-09-28 起每条必标，别删）：
#   [官方] 厂商官方文档/政策页直接列出该 token
#   [一致] 多个独立第三方爬虫目录站一致记录该 UA（无官方页）
#   [存疑] 来源互相矛盾或命名混乱 —— 不收录进本文件
#   ★ 收录判据不是"有没有官方背书"，而是"能不能被一致证实存在"。
#     加一条 Allow 的上限收益为零、下限风险也为零；
#     但在文件里写一个查不实的 token，下限风险是让后人误以为已覆盖某厂商。
#
# 未被本文件收录的高风险重灾区（别照抄第三方 SEO 稿）：
#   BaiduSpider-AI / BaiduBot / Alibaba-Crawler-AI / AlibabaBot
#     —— 命名与官方 token 高度相似、来源互相打架，百度官方 spider 页未提及，
#        阿里无任何官方爬虫页。2026-09-28 核验后剔除。
#
# 变更史：
#   2026-09-28 核验并差异化收录中国大模型 token（保留 4 / 剔除 4）；
#              新增来源等级标注；与线上 di3zongdui.github.io 对齐。
#   2026-09-19 删除 GPTBot-User（不存在该 token）；
#              补 Kimi 三件套与 Claude-SearchBot、Applebot、Googlebot、DeepSeekBot；
#              注释改独立行。
#   2026-08-16 初版。
# ============================================================
