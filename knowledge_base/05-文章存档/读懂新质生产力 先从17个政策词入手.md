# 读懂新质生产力 先从17个政策词入手

**作者：作者：郭雁冰，CGL 集团高级副总裁**
**同步自：微信公众号「侠客乔治」**

![读懂新质生产力 先从17个政策词入手](https://di3zongdui.github.io/knowledge_base/images/xinzhi_production_opinion_header.png)

2026 年 10 月 9 日，中共中央、国务院印发《关于发展新质生产力的意见》，新华社受权发布。同一天，国家发展改革委有关负责同志就《意见》答记者问。

政策文件天生是写给各级部门看的，它有自己的一套词。这份文件里最常出现的“新质生产力”，很多人第一眼看不懂它到底指什么。

这篇只做一件事：把这些词换成日常说法。先讲每个人各读到什么、政策词怎么翻，再回头拆文件本身。

| 7 | 5 | 19 | 4 |
|---|---|---|---|
| 个部分 | 个方面 | 项重点举措 | 条原则 |

文件不长。国家发展改革委在答记者问里给它的定位只有一句：**“为全国发展新质生产力确立了统一思想行动的标尺”**。

“标尺”两个字说的是，它不是告诉各地该造什么，而是告诉各地该拿什么去量。量什么，比造什么更靠前。

先不看条目。这份文件其实只说了三句话，后面所有条目都能放回这三句话里对位置。

> **第一句　它不是只布置任务，一半力气用来纠偏**
> 过去一段时间，实践里跑出过三种走偏：把新质生产力等同于新兴产业和未来产业、只顾发展不动改革、各地赛道雷同。

> **第二句　它挑的尺子是“全要素生产率”，这是唯一一个花钱买不到的指标**
> 人、钱、设备还是那些，产出要更多。多买设备、多招人，数字也会涨，但那不算新质生产力。

> **第三句　最难懂的不是道理，是词**
> 整份文件最容易卡住人的，是那些政策术语。第二节把 17 个词逐个换成日常说法，可以截图存下来当工具用。

## 一、同一份文件，不同的人读到的是不同的事

文件是发给全国的，但每个人真正用得上的部分不一样。下面按文件实际写了什么分述。

**做企业的**，最直接的有两处。一处是“谁来出题”变了：文件鼓励企业牵头国家科技任务，支持有能力的民营企业牵头承担国家重大技术攻关任务。另一处是“钱的口子”松了：企业研发准备金制度、研发费用加计扣除比例提高、首台（套）首批次应用政策——合起来说，就是让企业敢把钱投到研发上，而且投进去有税收上的实在好处。

**在企业里做管理的**，对应的是评价标准的一次切换。文件要求科研人员的考核评价激励，与报项目、发论文、评奖励这些动作适度脱钩，“防止简单按人才‘帽子’定薪酬、定职称、定待遇”，同时健全“新八级工”制度、畅通产业工人的上升通道。换成日常说法：看一个人，看的是他干成了什么，而不是他头上顶着什么头衔。

**做投资的**，文件在体制机制这一部分留了整段篇幅：鼓励和规范发展天使投资、风险投资、私募股权投资，完善长期资本“投早、投小、投长期、投硬科技”的支持政策，壮大耐心资本；丰富科技创新债券产品体系，支持优质科技型企业上市融资，优化并购重组、股权激励等制度。这里说的“耐心资本”，就是那种不急着短期回本、愿意陪着企业长跑的钱。文件还提到，要更好发挥政府投资基金的引导带动作用，鼓励银行开发符合新质生产力特点的贷款产品，发展覆盖科技创新全链条的保险产品。

**在做学业和职业选择的人**，有两处相关：一是“实施基础学科和交叉学科突破计划”，二是“培养新质生产力发展急需人才”。前者指向基础学科的长期投入，后者指向急需岗位的人才通道。

**地方和园区**，最该注意的是那几条禁令。文件写明：不能脱实向虚、贪大求全、搞泡沫化，不能出现产业空心化或产业断层，不能盲目求新、顾此失彼；严禁借发展新质生产力之名违规滥用政策；对一哄而上、盲目投资造成重大损失的，要严肃追究责任。发改委把这一层说得更直白：政府要“有所不为”，严禁借发展新质生产力之名搞恶性招商引资、盲目“跟风”上项目、乱“烧钱”。

## 二、文件里的政策词，逐个换成日常说法

> **这一节可以当工具用。**
> 整份文件最难的不是道理，是词。下面这 17 个词，是普通人读这份文件时最容易卡住的地方——把左边换成右边的说法，文件就好读了。建议截图存下来。

| 文件里的说法 | 换成人话怎么说 |
|---|---|
| 以全要素生产率大幅提升为核心标志 | 人、钱、设备还是那些，产出要更多；不靠多花钱堆投入 |
| 加强原创性颠覆性科技创新 | 做别人没做过的技术，不是跟在别人后面改一改 |
| 建立企业研发准备金制度 | 让企业提前留出一笔专款做研发，不用年年临时打报告批 |
| 提高研发费用加计扣除比例 | 花在研发上的钱，算应纳税所得额时可以多扣一些，等于少交税 |
| 首台（套）、首批次应用政策 | 新设备、新材料的第一台第一批，先想办法让它有人敢用 |
| 改造提升传统产业 | 老行业用新工具重做一遍，不是把老行业关掉 |
| 促进实体经济和数字经济深度融合 | 工厂、门店、物流这些“实”的，和软件、数据这些“数”的接上 |
| 中试基地 | 实验室成果走到批量生产之间的试产车间 |
| 高价值应用场景 | 真有人在用、真能验收、真能算出价值的具体用法 |
| 分业施策 | 一个行业一个办法，不搞一套模板抄到底 |
| 先立后破 | 新路子先跑通站稳，老的再慢慢退，不能先砸了再说 |
| 脱实向虚、搞泡沫化 | 只炒概念、只做估值，不落到真实的产能和产品上 |
| 产业空心化、产业断层 | 老产业退得太快、新产业还没接上，中间空了一段 |
| 壮大耐心资本 | 支持那种不急着短期回本、愿意陪着企业长跑的钱 |
| 防止简单按人才“帽子”定薪酬、定职称、定待遇 | 不给头衔发钱，给干成事的人和岗位发钱 |
| 健全“新八级工”职业技能等级制度 | 技术工人也有从低到高的等级通道，不用非得转去当管理 |
| 安全、可靠、可控 | 用起来不能失控，出了问题能及时发现、及时处置 |

## 三、文件里最容易被读反的一句话

工具先放一边，回到文件本身。答记者问里有一句，和很多人的第一反应正好相反：

> 发展新质生产力不只是培育新兴产业和未来产业，传统产业改造升级也能发展新质生产力。
> ——国家发展改革委有关负责同志就《意见》答记者问

很多人听到“新质生产力”，第一反应是：老行业要让位，腾出手去做人形机器人、低空经济、生物制造。

这句话把顺序说反了。它说的是：**老行业不是要被替换掉，老行业本身就是新质生产力的产地之一。**

为什么能这么说？答记者问给了一个区分：新质生产力讲的是生产力的“质态”，也就是质量高低；而行业只是外在的形态。一个行业只要效率和质量上去了，不管是新兴产业还是传统产业，都算。

所以文件里那四条原则——创新主导、改革为要、因地制宜、先立后破——不是挂在墙上的话。

| 四条原则 | 发改委给的定位 | 针对的做法 |
|---|---|---|
| 创新主导 | 把创新作为逻辑起点 | 脱离实际的盲目布局和投资 |
| 改革为要 | 把改革作为关键一招 | 重发展轻改革，割裂发展、改革任务 |
| 因地制宜 | 把立足资源禀赋作为实践准则 | 赛道雷同，上下一般粗，同一种模式 |
| 先立后破 | 把新旧动能平稳接续作为方法路径 | 忽视传统产业升级改造，一哄而上 |

这四条，每一条都对应着一种走偏的做法。发改委说得很直接，它们是“针对实践探索中出现的……忽视传统产业改造升级、重发展轻改革等问题的纠偏”。

## 四、“全要素生产率”换成日常说法

文件把“全要素生产率大幅提升”定为核心标志。这个词听着专业，说的事却很日常。

想象一家工厂：100 个人、10 台设备，一年做 1 万件产品。

想把产量提到 1.3 万件，最省事的办法是再加 30 个人、再加 3 台设备。人多设备多，产出自然多——这是靠“多投入”换增长。

文件要的不止这个。它要的是：**人还是 100 个，设备还是 10 台，产量从 1 万件变成 1.3 万件。**

多出来的那 3,000 件，不是靠多花钱买来的，是靠技术更好、流程更顺、管理更细挤出来的。这部分“没多投入却多出来的产出”，就是全要素生产率。

**为什么偏偏用它当尺子？因为它是唯一一个砸钱买不到的指标。** 多买设备、多招人，数字也会涨，但那不算新质生产力。把尺子放在这里，等于先把“堆投入”这条捷径堵上。

## 五、文件里的“人工智能+”是怎么写的

这一段最需要看清细节，因为很多人只看了一句标题，没看它在文件里的位置和口气。

**第一，它不是单独一章。** “人工智能+”放在第二个方面“推动科技创新和产业创新深度融合”里，和“改造提升传统产业”“培育壮大新兴产业”“前瞻布局未来产业”排在一起。

> 全面实施“人工智能+”行动。推进人工智能对传统产业的改造……因地制宜、分业施策布局国家人工智能行业应用中试基地和高价值应用场景，大力推动人工智能在各行业应用。
> ——《中共中央 国务院关于发展新质生产力的意见》

这句话的落点很清楚：让人工智能去改造传统产业，而不是另起炉灶；落到一个一个行业上去用，而不是停在概念上。

**第二，它前面有两个限定词：因地制宜、分业施策。**

这两个词说的是同一件事——先试点、再铺开，一个行业一个办法，而不是一套模板用到底。文件点名要两类东西：“行业应用中试基地”和“高价值应用场景”。

中试基地，就是实验室成果走向批量生产之间的那个试产车间：先把东西真做出来、真跑一遍，再谈推广。高价值应用场景，就是真有人在用、真能验收、真能算出价值的那些具体用法。

**第三，它配了安全条款。** 原文要求构建“技术监测、风险预警、应急响应体系，确保人工智能安全、可靠、可控”。

把这三层连起来看，文件对“人工智能+”的态度是完整的：**大力推进，但按行业推进，同时把安全的笼子先搭好。**

## 六、19 项举措分在五个方面，为什么“科技创新”排第一

发改委解释过这个排序：科技创新能催生新产业、新模式、新动能，是发展新质生产力的核心要素。

| 方面 | 文件里的动作 |
|---|---|
| 一、大力推进科技创新 | 5 项重大任务：加强原创性颠覆性科技创新、加快突破关键核心技术、统筹国家战略科技力量建设、强化企业科技创新主体地位、加速科技成果向现实生产力转化 |
| 二、推动科技创新和产业创新深度融合 | 改造提升传统产业、培育壮大新兴产业、前瞻布局未来产业、促进实体经济和数字经济深度融合、**全面实施“人工智能+”行动** |
| 三、着力推进发展方式创新 | 构建绿色低碳循环发展经济体系、优化绿色发展政策工具箱、积极推进能源革命 |
| 四、扎实推进体制机制创新 | 聚焦科技和经济紧密结合深化改革、完善市场监管制度、加大金融创新产品供给、在全球配置先进生产要素 |
| 五、深化人才工作机制创新 | 培养新质生产力发展急需人才、健全人才使用和流动政策 |

这五个方面的分工很清楚：第一方面管“技术从哪来”，第二方面管“技术怎么变成产业”，第三方面管“用什么方式发展”，第四方面管“卡在哪一层制度上”，第五方面管“靠谁来干”。

第一方面里，“谁来干”又分了两条线：政府这条线是“统筹国家战略科技力量建设”，市场这条线是“强化企业科技创新主体地位”。后一条文件写得很具体——鼓励科技型中小企业多投研发，支持有能力的民营企业牵头去承担国家的重大技术攻关任务。

## 收束：它其实划了两条线

这份文件的分量，不在它列了多少件该做的事，而在它同时划了两条线。

一条是往哪走：科技创新、产业创新、发展方式创新、体制机制创新、人才工作机制创新，五个方面 19 项，拿“全要素生产率大幅提升”当核心标志。

一条是不能怎么走：不能脱实向虚、贪大求全、搞泡沫化，不能出现产业空心化或产业断层，不能盲目求新、顾此失彼。

发改委给这份文件的定位，用的是“标尺”两个字。尺子不挑对象，量的是同一件事：同样的投入，产出有没有变多。
