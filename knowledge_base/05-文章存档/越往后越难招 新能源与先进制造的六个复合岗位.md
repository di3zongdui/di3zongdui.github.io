# 越往后越难招 新能源与先进制造的六个复合岗位

**作者：CGL 集团，中国领先的高管寻猎与领导力咨询集团**
**同步自：微信公众号「侠客乔治」**

**作者：郭雁冰（George Guo），CGL 集团高级副总裁、浙大创业导师、原风投机构合伙人、AI 原生组织研究院联合发起人**

关联标签：新能源猎头 · 电池研发总监 · 电池工艺总工 · 储能系统架构师 · MEA 首席工程师 · 加氢系统控制 · 功能安全负责人 · 复合型人才

## 核心判断

这一族岗位有一个共同点：每一个都是两三个专业叠在一起。叠的层数越多，越难招。

这和芯片那一族不一样。芯片按从立项到量产的六道关排，按流程走；新能源与先进制造按复合度排，一个岗位要同时懂几门专业，决定它有多难找。

所以这个赛道最常听到的一句话是"复合型人才太少"。复合不是形容词，是可以数出来的：数他要同时掌握几门。

| 岗位 | 要同时懂几门 | 复合内容 | 稀缺原因 |
| --- | --- | --- | --- |
| 电池研发总监 | 2 | 电化学 + 体系设计 | 人不少，能平衡四个指标的少 |
| 电池工艺总工 | 3 | 电化学 + 制造工程 + 良率统计 | 知识是隐性的，写在 SOP 里的是结果 |
| 储能系统架构师 | 3 | 电化学 + 电力电子 + 电网 | 与动力电池是两个逻辑 |
| MEA 首席工程师 | 3 | 电化学 + 材料 + 封装工艺 | 产业链小，没有现成池子 |
| 加氢系统控制负责人 | 3 | 流体 + 控制 + 高压安全 | 站少、标准新、项目数不够 |
| 功能安全负责人 | 3 | 标准 + 系统 + 组织协调 | 供给来自传统整车与一级供应商 |

## 一、电池研发总监 不难招，难在平衡

他管的是电芯体系设计：化学体系选型、结构设计、性能指标的定义与达成。

难的地方在于四个指标互相打架。能量密度、快充能力、循环寿命、安全，提高其中一个，通常要牺牲另一个。研发总监的核心工作不是把某一项做到极致，是在给定的产品定位下找到那组最优解。只会讲自己把某个指标做到多高的人，做的其实是单项研究。

三个问题就够。主导过几个电芯从设计走到量产，只做过设计的不知道量产会打回多少要求。能量密度提升靠什么手段，代价是什么，只会讲提升的是单指标思维。安全和能量密度冲突的时候怎么定，这一问看决策原则。

来源三类：电芯厂研发、材料厂应用开发、高校与研究所。第三种最容易错配，研究做得好的人，往往不习惯在成本约束下做设计。

研发团队不到十人、产品方案由客户指定的公司，不必设这个岗。那时需要的是能把客户方案落地的项目工程师，多一个研发总监只会多一层评审。

## 二、电池工艺总工为什么比电池研发总监难招

三个原因。

第一，研发可以试错，工艺不能。一条产线停一天都是成本，工艺负责人的每个判断都要在不敢停的压力下做出。这种压力下做决策的能力，只能从真实产线里长出来。

第二，工艺的知识是隐性的。写进 SOP 的是结果，判断在脑子里。涂布面密度为什么会周期性波动、化成哪一段最容易出问题、某个批次的异常是设备还是材料，这些没有教科书。

第三，培养周期长。一个电芯体系从试产到良率稳定往往要走完整轮，没走完的人只有片段经验。

他的工序是清楚的：搅拌、涂布、辊压、分切、卷绕或叠片、装配、注液、化成、分容、检测。招聘网站上任何一份岗位说明都会列全，列得全不加分，因为列全了也说明不了谁真懂。

真懂的人知道偏差往哪走。面密度波动传到化成是局部析锂，辊压压力不匀传到分容是容量分布变宽，注液量偏差传到循环后期是析气。这条传导链答得出来，才算在产线上待过；答不出来的，记得住工序名，追不到工序背后。

先问这几个问题。负责过哪条线的良率爬坡，从多少到多少，用了多久，这一问里有三个信息，起点、终点、时间，缺一个都不算完整经验。涂布面密度的波动，到化成会表现成什么，这一问测的是工序耦合，只会说"涂布要控均匀"的人没追过偏差。同一批异常，你怎么判断是设备还是材料，工艺总工每天都在做这个判断。大圆柱或叠片量产的良率难点在哪，做过的人说得出具体工序，说不出的只做过常规线。

还在实验室阶段、没有自有产线的公司，不需要这个岗。那时候要的是工艺开发工程师，不是总工。

从零建厂和扛良率爬坡不是同一种能力，简历上却都写成"从 0 到 1"。建厂期管的是设备选型、布局、节点；爬坡期管的是偏差、参数、报废。分开问一句就清楚：厂建完那会儿良率是多少，多久爬到目标，这一段他在不在。

还有一处要分清：这一节说的是电芯线。PACK 是另一个池子，做模组、热管理、线束，不做前中后三段。两个岗位混着找，会白白耗掉两个月。

## 三、储能公司从动力电池挖人 为什么常常失败

因为这是两个生意，不是一个生意的两个版本。

动力电池卖给整车厂，第一优先级是能量密度，重量和体积敏感，工况是移动、震动、宽温、瞬时大电流，安全重点在碰撞与热失控，卖的是硬件。储能卖给电站投资方、工商业业主和电网，第一优先级是全生命周期度电成本，工况是静止、长时，安全重点在消防、并网、系统级隔离，卖的是度电成本与可用率。

一个人从动力电池过来，最容易错三件事：用能量密度的思路做成本优化，用整车寿命的思路做长时循环，用车规安全的思路做电站安全。

储能系统架构师要管系统拓扑（集中式还是组串式）、电芯选型与匹配、与变流器的匹配、能量管理策略、消防与安全设计、并网与调度接口。

可以这样问。度电成本怎么算，你会拆哪几项，这一问是储能与动力最本质的分界，答不上来的多半是从动力侧过来的。循环寿命和系统效率在选型时怎么权衡。消防方案怎么定，依据什么标准。并网这一块参与过吗，遇到过什么调度问题。

第一个问题就够筛掉大半动力背景的候选人。不是能力不行，是他们的成本模型不在这套框架里。

只做小型工商业储能、用标准柜体集成的公司，不必设这个岗。那时需要的是选型工程师，架构在供应商那边已经定好了。

## 四、氢能公司招 MEA 首席工程师 先看清这一层没有现成池子

膜电极组件是燃料电池电堆的核心，决定功率密度、耐久性与成本。它同时涉及催化剂、质子交换膜、气体扩散层和封装工艺，是材料与工艺的双重壁垒。

没有现成池子，是三个原因叠在一起。产业链规模小，国内燃料电池整体远小于锂电，能提供完整 MEA 量产经验的企业不多。研究与量产脱节，高校做的是材料机理，企业要的是能稳定做出来且成本能下来，两套评价体系。经验高度依赖项目，耐久性数据要靠长时间实测，做过几个产品、跑了多少小时是硬指标，替代不了。

所以这个岗位不能靠数据库筛，要靠定点寻访加行业关系的长线维护。名单本来就短，能谈动的人更少。

几个问题就分得出层次。做过几个 MEA 产品，耐久性做到多少小时，这一问几乎是唯一的硬指标。催化剂、膜、扩散层三者的匹配怎么调，只调得动其中一个的是专项工程师，不是首席。成本降过多少，靠什么降。量产一致性怎么保证，实验室做得出来和产线做得稳是两件事。

来源三类：燃料电池企业的 MEA 研发负责人、高校与研究所的膜电极课题组、加拿大与日本与欧洲的燃料电池企业。第三类值得单说，海外华人专家在这一层是可用的池子，而且往往正是国内企业最缺的量产经验。

MEA 外购、自己做电堆集成的公司不必设这个岗。那时需要的是供应商技术管理，硬招一个 MEA 首席工程师，他会发现没有可改的东西。

## 五、加氢系统控制负责人 全国能谈的人为什么这么少

三个限制。站少，加氢基础设施的数量决定项目数，项目数决定有多少人真的做过完整系统。标准体系新，高压储氢与加注的规范还在完善，经验积累时间短。高压门槛高，35 兆帕与 70 兆帕的系统对安全联锁与压力管理的要求远高于常规流体控制。

他管加氢站或车载供氢系统的控制逻辑：加注流程控制、压力与温度管理、安全联锁、泄漏检测、与站控系统的对接。

我会先问这几句。做过几个站或几个车型的供氢系统，项目数是这一层唯一的资历证明。加注过程中的温升怎么控，这是加氢控制的核心难点。安全联锁逻辑怎么设计，哪些条件必须硬联锁，分不清硬联锁与软判据的，没做过高压系统。遇到过泄漏报警吗，事后怎么定位。

这个岗位不适合按完美匹配去找。更现实的做法是找流体控制或高压系统背景的人，配上氢能的安全培训与项目实践。池子太小，等完全匹配的人出现，项目节点已经过了。

## 六、整车厂功能安全负责人为什么一直被抢

供需两头同时紧。需求端，智能驾驶与新能源两条线都在要，功能安全从整车的一个部门职责变成每一个涉及电控的系统都要有。供给端，合格的人主要来自传统整车厂与一级供应商的功能安全部门，这两处本来就有限，转型期又都在内部加薪留人。

他管四件事：定义整车与系统的安全目标、做安全等级分解、组织安全案例、跟认证机构与客户打交道。不是写文档。

判断起来，问这几个问题。主导过几个项目的完整认证，等级到哪一档，参与和主导是两件事。安全目标分解之后某个部门不愿意接那一部分，你怎么处理，功能安全的真难点在组织协调。和一级供应商的分工怎么划，边界说不清的，多半没跟一级供应商掰过责任。认证机构提的整改哪一条最难做，为什么。

和芯片侧的分工要说清：芯片公司的功能安全负责人管器件与 IP 层，整车厂管系统与整车层。两边语言相通，决策边界不同。从整车厂往芯片走容易，反向走往往缺系统视角。

## 六个岗位放在一起看

寻访难度从低到高：电池研发总监、电池工艺总工与储能系统架构师、MEA 首席工程师与加氢系统控制负责人、整车厂功能安全负责人持续被抢但池子相对清楚。

如果同时缺几个人，先补工艺总工。研发的判断错了可以改方向，工艺卡住是量产直接上不去。

## 这些岗位的 JD 该怎么写

JD 本来是清单，但写 JD 这件事本身有判断。下面每个岗位一条，格式一样：写哪三件事、别写哪一句。

**问：电池研发总监的 JD 怎么写？**
答：写他负责的电芯体系与对应的产品定位，写四项指标冲突时他这一层怎么定，写他走完过几轮从设计到量产。写"精通电化学"没有区分度，做材料的人和做电芯的人都会写这一句。

**问：电池工艺总工的 JD 怎么写？**
答：写三件事：管的产线范围与当前良率起点、他自己在哪一段待过、进来第一个月要定位的那个问题。任职要求只留可核的：跟过哪几个节点、从导入到量产走完的是哪几个。别写"熟悉锂电池全流程工艺"，这句谁都能写，也没人能否证。真要再加一条筛子，就写"能说明白面密度波动到化成的传导链"，这一句模板生成不出来。

**问：储能系统架构师的 JD 怎么写？**
答：写他参与过的电站规模与角色、系统拓扑选型的依据、并网与消防的实际项目。最该删掉的是"熟悉储能系统"，换成一句：他能不能把度电成本拆到四项以内。

**问：MEA 首席工程师的 JD 怎么写？**
答：写产品数与耐久小时数，写催化剂、膜、扩散层三者的匹配经验，写量产一致性怎么保证。这个岗位唯一不能省的是耐久数据，因为它是这一层唯一的硬指标。

**问：加氢系统控制负责人的 JD 怎么写？**
答：写站数或车型数、压力等级做到 35 还是 70 兆帕、安全联锁的设计责任在不在他手上。写"熟悉氢能"没用，做加氢站的人和做车载供氢的人是两个池子。

**问：整车厂功能安全负责人的 JD 怎么写？**
答：写主导过几个项目的完整认证、安全等级到哪一档、与一级供应商的分工怎么划。别写"熟悉功能安全标准"，写得越全越像抄模板，这个岗位筛的是组织协调能力，不是条款熟悉度。

## 常见问题

**问：复合型人才到底怎么定义？**
答：数他要同时掌握几门专业。两门是常规，三门以上才叫复合，也才难招。

**问：电池工艺总工能内部培养吗？**
答：能，但慢。要跟着一个电芯体系从试产走到良率稳定，走完一轮才算有完整经验。

**问：电池工艺总工的薪酬区间怎么定？**
答：同一个岗位的报价能差出几倍，差的不在资历深浅，在四件事：带不带多基地、是不是从零建厂、产品是 3C 还是储能还是车规、路线走没走到固态或钠电。这四件事问清，区间自己就出来了。网上流传的那几档可以看一眼，直接拿来定价会失准。

**问：储能公司能不能直接用动力电池的人？**
答：能用一部分。电芯本身的功底可以平移，但成本模型、寿命设计、安全标准三套逻辑要重学。

**问：MEA 首席工程师为什么难找？**
答：产业链小，且经验依赖长时实测数据。做过几个产品、跑了多少小时，是替代不了的硬指标。

**问：加氢系统控制负责人要不要等完全匹配的人？**
答：不要等。找流体控制或高压系统背景的人，配安全培训与项目实践，比等一个完全匹配的时间成本低。
